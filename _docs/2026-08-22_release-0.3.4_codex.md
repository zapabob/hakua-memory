## Scope

This release candidate contains documentation, benchmark, packaging, and
verification work only. No memory algorithm, embedding backend, graph edge
type, RAG capability, database schema, public API redesign, or asynchronous
CompositeMemory refactor was added.

quality sprint recorded repository-wide pytest collection failure from the
duplicate `tests/test_comprehensive.py` and `scripts/test_comprehensive.py`

## Changes

`scripts/benchmark_external_libraries.py` now runs paired same-host
comparisons for hakua-memory RAG chunking against LangChain Text Splitters and
LlamaIndex SentenceSplitter, and for Semantic Graph lexical retrieval against
rank-bm25. It records package versions, host metadata, clean-worktree status,
dataset and query configuration, raw durations, summary statistics, confidence
intervals, paired tests, Holm correction, and validation results.

`benchmarks/requirements.txt` pins the opt-in comparison environment to
LangChain Text Splitters 1.1.2, LlamaIndex Core 0.14.24, rank-bm25 0.2.2,
SciPy 1.18.1, and Matplotlib 3.11.1. These dependencies are not added to the
published package's base or optional feature extras.

`README.md` now contains executable base and RAG examples, repository-external
runtime paths, isolated benchmark setup, comparison scope limits, statistical
method, reproducibility commands, and a recorded hardware run. The examples
were executed in isolated homes using the 0.3.4 candidate environment.

`pyproject.toml` and the metadata assertions in `tests/test_config.py` and
`tests/test_benchmark.py` now use version `0.3.4`. Generated error-bar images
are ignored alongside generated benchmark JSON.

## Benchmark method and evidence

The clean candidate measurement used:

- Windows 11, Python 3.12.13, AMD64 Family 23 Model 96 CPU
- `synthetic-business-v1`, seed 42, 40 samples and 40 queries
- warmup count 5, 30 paired repetitions, randomized variant order
- mean, median, standard deviation, p50, p95, p99, and 95% confidence interval
- two-sided paired Wilcoxon signed-rank test and paired t-test sensitivity
- Holm correction across the three Wilcoxon comparisons

The machine-readable evidence was written outside the repository at:

`H:\\codex_temp\\hakua-memory-release-0.3.4\\external-clean-e2bbb3c.json`

The candidate commit recorded in that file is
`e2bbb3c8bfd3bbfcd7a5e508a757917919dd5e89`, and
`git_worktree_clean` is `true`. The error-bar figure was written to:

`H:\\codex_temp\\hakua-memory-release-0.3.4\\external-clean-e2bbb3c.png`

The dataset-specific expected-record top-k=5 hit rates were 33/40 for
hakua-memory and 38/40 for rank-bm25. This is a synthetic validation check,
not a cross-domain quality claim. Dense retrieval, end-to-end answer quality,
memory footprint, GPU performance, and external Ebbinghaus equivalents remain
explicitly unmeasured.
